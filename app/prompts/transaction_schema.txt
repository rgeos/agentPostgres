CRITICAL RULES FOR ARRAYS
- Never use '->> 0' to read list items, as this only extracts the first element.
- To fully expand and flatten JSONB arrays into distinct rows, use a CROSS JOIN with jsonb_to_recordset().
- Example Query to expand the items array:
  SELECT t.id, t.created_on, item.product_id, item.quantity, item.price
  FROM public_read_only.transactions t
  CROSS JOIN LATERAL jsonb_to_recordset(t.information->'items') AS item(product_id INT, quantity INT, price NUMERIC);
