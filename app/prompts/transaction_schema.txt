JSONB 'information' Schema Breakdown & Access Paths:

* Order Identifier: (information->>'orderId')::bigint
* Customer Name: information->>'customerName'
* Financial Amount: (information->>'amount')::numeric
* Fulfillment Status: information->>'status'
* Shipping Address (Nested Object): information->'shippingAddress'
  * City Name: information->'shippingAddress'->>'city'
  * Street Address: information->'shippingAddress'->>'street'
  * Postal Zip Code: information->'shippingAddress'->>'zipcode'
* Purchase Items (Nested JSON Array): information->'items'
  * Accessing an element by index (e.g., first item): information->'items'->0
  * Nested Array Fields (Requires indexing or array expansion):
    * Product ID String: information->'items'->0->>'productId'
    * Product Name String: information->'items'->0->>'productName'
    * Item Unit Price: (information->'items'->0->>'price')::numeric
    * Item Quantity: (information->'items'->0->>'quantity')::integer

CRITICAL RULES FOR ARRAYS
- Never use '->> 0' to read list items, as this only extracts the first element.
- To fully expand and flatten JSONB arrays into distinct rows, use a CROSS JOIN with jsonb_to_recordset().
- Example Query to expand the items array:
  SELECT t.id, t.created_on, item.product_id, item.quantity, item.price
  FROM public_read_only.transactions t
  CROSS JOIN LATERAL jsonb_to_recordset(t.information->'items') AS item(product_id INT, quantity INT, price NUMERIC);
